# 影视设置页 + 详情页与独立播放页

影视相关的全局配置集中到「系统 → 影视」设置页（TMDB 配置从存储空间页迁入；新增转码配置：硬解方式 auto/VA-API/QSV/NVENC/软解、设备路径、ffmpeg 单任务线程数），均存于系统配置表、即时生效。硬解失败策略按模式区分：`auto` 启动失败自动回退软解；显式指定的硬解方式启动失败则播放直接报错，引导用户修改配置，不做静默回退。

浏览交互从「海报墙 → 弹窗播放」改为「海报墙 → 详情页 → 独立播放页」：详情页为 Jellyfin 风格（backdrop 横幅 + 海报 + 元信息 + 简介，电视剧含剧集列表；未识别条目展示文件信息简版详情并可修正匹配）；播放页为独立全屏路由（`meta.standalone`，不渲染顶栏/侧栏），电视剧支持页内选集与播完自动连播。

## Considered Options

- **硬解失败一律自动回退软解**：用户无感，但掩盖配置错误，排障困难，被排除（auto 模式保留回退）。
- **详情页加演职员表**：更接近 Jellyfin，但需额外调 TMDB credits 接口并落库，数据量与接口调用翻倍，本期不做。
- **播放页复用弹窗组件**：弹窗天然受外壳布局限制，无法承载选集面板与连播，改为独立路由页。

## Consequences

- 元数据刷新为显式操作（详情页按钮）+ 启动时对缺失背景图的存量数据自动补抓。
- 播放页需要处理剧集切换时的转码会话销毁/重建与进度上报。
- 前端新增 `meta.standalone` 路由标记，App 根组件据此跳过外壳布局。

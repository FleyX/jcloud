# PRD：视频播放字幕可用性与时间轴修复

## Problem Statement

独立视频播放页会把 PGS 位图内嵌字幕当作普通文本字幕展示。用户选择后，后端尝试将 `hdmv_pgs_subtitle` 提取为 WebVTT，必然失败并返回 500。

外置字幕在转码/HLS 播放时与视频时间轴不一致：视频转码会从续播点或 seek 点建立从 0 开始的相对时间轴，但字幕文件仍使用原片绝对时间。结果是前段字幕错位，播放一段时间后看不到对应字幕。外置字幕转换缓存只按文件节点 ID 命名，字幕文件内容变化后可能继续返回旧 VTT。

## Solution

播放信息只暴露可转换为 WebVTT 的文本内嵌字幕轨，隐藏 PGS 等位图轨。字幕输出保留原始正文内容；在 HLS/转码会话中，后端按当前会话起点将字幕时间戳转换为视频流相对时间，直放继续使用原片时间轴。外置字幕转换缓存按文件内容版本区分，文件内容变化后生成新缓存。

## User Stories

1. 作为用户，我希望 PGS 等不可转换的内嵌字幕不出现在字幕菜单中，以免选择后触发字幕提取失败。
2. 作为用户，我希望可转换的文本内嵌字幕仍能正常显示，以便继续使用 MKV 内置字幕。
3. 作为用户，我希望播放页遇到不支持的内嵌字幕时视频本身继续播放，以免字幕问题阻断观看。
4. 作为用户，我希望从头播放时外置字幕与视频原始时间轴一致，以便字幕在正确的对白时刻出现。
5. 作为用户，我希望从历史进度续播时外置字幕与当前视频画面一致，以便续播不会出现整体偏移。
6. 作为用户，我希望拖动进度条并重建转码会话后字幕立即重新对齐，以便 seek 不会破坏字幕同步。
7. 作为用户，我希望电影多版本、电视剧集和其他视频使用相同的字幕时间轴规则，以免不同媒体类型表现不一致。
8. 作为用户，我希望修改外置字幕文件后再次播放能得到新内容，以免旧缓存遮蔽文件更新。
9. 作为用户，我希望字幕正文内容保持原样，不因播放器修复而被擅自清理、翻译或重排。

## Implementation Decisions

### 1. 内嵌字幕可用性

- 以内嵌字幕轨的编码类型判断可用性，只将可转换为 WebVTT 的文本轨加入播放信息和统一字幕列表。
- PGS 等位图轨不作为播放页可选字幕，也不参与默认字幕选择和语言偏好匹配。
- 播放信息的内嵌轨列表与统一字幕列表保持一致，避免其他客户端通过原始轨列表重新选中不可用轨。
- 已知文本轨若因文件损坏或格式异常转换失败，按单轨失败降级，不影响视频播放；后端记录可排查日志。本期不做 OCR 或预转换验证。

### 2. 字幕时间轴

- 字幕时间轴以用户当前看到的视频时间轴为准。
- 直放时字幕使用原片绝对时间，不做偏移。
- HLS/转码时，字幕时间戳减去当前转码会话起点；从会话起点之前开始但在起点之后结束的 cue 从 `0` 秒开始显示；完全早于起点的 cue 不显示。
- 播放页在字幕资源地址中传递当前转码会话起点。转码会话因续播、seek 或超缓冲重建时，字幕资源同步使用新的起点并重新加载。
- 内嵌字幕和外置字幕遵循同一时间轴规则。

### 3. 外置字幕缓存

- 转换后的外置 `srt`/`ass`/`ssa` 字幕以文件内容版本作为缓存身份，而不是只使用文件节点 ID。
- 优先使用文件节点 hash；hash 缺失时使用可用的文件大小与最后修改时间等版本信息。
- 文件内容版本变化后生成新的 VTT，不再复用旧版本；旧缓存不影响播放，可由后续清理机制回收。
- 本地 `vtt` 仍可直接返回；本期不改变字幕正文内容，也不增加异常 cue 或广告 cue 清理规则。
- 外置字幕缓存策略同时适用于本地文件和远程挂载文件。

### 4. 与现有播放架构的关系

- 保持现有“探测入库 + 直放/HLS 转码”链路，遵循 ADR 0017。
- 不新增数据库表或字段，不改变外部字幕的扫描关联规则和默认字幕命名规则。
- 保持现有字幕接口的鉴权、版本选择和文件归属校验；仅扩展字幕时间偏移参数及缓存版本语义。
- 无需 Flyway 迁移。

## Testing Decisions

- 后端测试缝为播放服务集成测试：使用 Spring Boot、`application-test.yml` 和真实 PostgreSQL，沿用现有媒体播放测试；只断言播放信息、字幕响应和缓存的外部行为。
- 前端测试缝为播放逻辑测试：验证转码会话起点变化时外置字幕资源带上对应偏移，直放不带偏移，seek 重建后使用新偏移。
- 后端覆盖：PGS 轨被过滤、文本轨保留、字幕 cue 按偏移转换、起点前跨界 cue 从 0 秒开始、完全过期 cue 被移除、不同内容版本得到不同缓存。
- 后端覆盖：电影版本、电视剧集和其他视频均能按文件明细行读取对应字幕。
- 前端覆盖：从头播放、续播、seek 重建和切换播放源时字幕 track 被重新加载。
- 回归覆盖：外置字幕归属校验、默认字幕选择、直放字幕时间戳和现有 UTF-8/GBK 处理不回退。

## Out of Scope

- PGS/OCR、字幕烧录、图片字幕转文本或保留 ASS 特效样式。
- 自动校准来源字幕的任意固定提前/延后偏移。
- 清理字幕正文中的重叠 cue、广告文本或其他内容质量问题。
- 字幕编辑、用户可配置字幕偏移、字幕下载与在线字幕搜索。
- 数据库结构变更和媒体扫描关联规则变更。

## Further Notes

- 当前“你的名字”复现样本的媒体时间轴从 0 开始，外置字幕含全片 cue；错位根因是转码流相对时间轴与字幕原片绝对时间轴未换算，而不是字幕只包含前二十分钟。
- 当前外置转换缓存确实存在内容更新后仍命中旧 VTT 的风险；本次将其作为独立但同属播放字幕链路的修复一并交付。
- 本 PRD 不修订既有历史 PRD；现有影视首页与收藏 PRD 未定义字幕播放行为。
- 无新增 ADR：过滤不可用字幕、按转码会话修正时间轴和版本化缓存均可逆，且没有形成需要长期保留的架构权衡。
- 领域术语已同步至 `CONTEXT.md`：内嵌字幕轨（Embedded Subtitle Track）。
- 本 PRD 拆分为工单 01（字幕服务过滤、时间轴转换与版本化缓存）和工单 02（播放页绑定转码会话字幕时间轴）。

# PRD：影视首页影院风改版与全站双主题

## Problem Statement

影视首页视觉稀疏平淡：卡片小且左对齐、右侧大片留白，缺少 Jellyfin/Netflix 等流媒体产品的影院氛围。整个应用也只有一套浅色主题，无法跟随系统或手动切换深色。

## Solution

两件事组合交付影院观感：

1. **全站双主题**：应用支持浅色/深色两套主题，默认跟随系统；用户可通过 PC/Mobile Header 右侧图标在「跟随系统 → 浅色 → 深色」三态间循环切换，选择持久化到 localStorage。公开登录/注册页渲染主题但不提供切换入口；独立播放页保持现有固定样式，不纳入本次主题适配。
2. **影视首页改版**：新增「最新电影」与「最新剧集」分区（竖版海报墙），分区顺序为「我的媒体 → 继续观看 → 接下来 → 最新电影 → 最新剧集」。不做 hero 轮播。

## User Stories

1. 作为用户，我希望应用默认跟随我的系统主题（浅色/深色），以便与系统观感一致。
2. 作为用户，我希望点击 PC 或移动端顶部栏右侧的主题图标在「跟随系统 → 浅色 → 深色」三态间循环切换，以便随时手动控制且能回到跟随系统。
3. 作为用户，我希望我的主题选择被记住（localStorage），以便刷新或重开浏览器后保持。
4. 作为用户，我希望系统主题变化时，处于「跟随系统」态的应用能实时跟随切换。
5. 作为用户，我希望登录、注册及所有非播放页面都能正确显示双主题，以便全站观感一致。
6. 作为用户，我希望主题按钮图标表示当前配置模式：跟随系统、浅色或深色；跟随系统时还应通过无障碍文本说明当前实际生效颜色。
7. 作为移动端用户，我希望移动端顶部栏同样有主题切换入口，且双主题在移动端全量生效。
8. 作为用户，我希望影视首页有「最新电影」分区，按电影入库时间倒序展示新收录电影。
9. 作为用户，我希望影视首页有「最新剧集」分区，按剧集最近一集入库时间倒序展示新收录剧集。
10. 作为用户，我希望最新电影按电影条目展示、最新剧集按剧聚合展示，以便同一部剧的多集不会刷屏。
11. 作为用户，我希望最新电影和最新剧集卡片显示相对入库时间，以便直观感知新旧。
12. 作为用户，我希望点击最新电影卡进入电影详情、点击最新剧集卡进入剧集详情，以便直达内容。
13. 作为用户，我希望最新电影和最新剧集不包含「其他」类型媒体库的条目，以便竖版海报墙整齐统一。
14. 作为用户，我希望最新电影和最新剧集各自最多展示 16 条并横向滚动，与其他分区行为一致。
15. 作为用户，我希望任一最新分区为空时该分区隐藏，以便页面不出现空占位。
16. 作为用户，我希望影视首页分区顺序为我的媒体、继续观看、接下来、最新电影、最新剧集，以便按媒体服务器惯例浏览内容。
17. 作为用户，我希望深色主题下影视模块（首页、媒体库、详情页）呈现影院氛围，且文件、系统、个人设置模块同样支持深色。

## Implementation Decisions

### 1. 双主题机制

- 新建 Pinia `theme` store，状态为 `system | light | dark`，默认 `system`。
- `light`/`dark` 模式通过 `<html>` 的 `dark` class 控制；`system` 模式读取 `prefers-color-scheme` 并监听变化。手动模式不响应系统变化。
- 主题按钮按配置模式显示：`system` 为跟随系统图标，`light` 为太阳图标，`dark` 为月亮图标；tooltip/无障碍文本补充当前实际生效主题。
- 在 Vue 挂载前由入口脚本读取 localStorage 和系统偏好设置 `<html>`，避免刷新时主题闪烁。无效主题值回退到 `system` 并写回规范值。
- PC Header 和 Mobile Header 均在头像左侧提供主题按钮；登录/注册页只渲染主题，不提供按钮。独立播放页保持现有固定样式，不响应本次主题视觉改造。
- Tailwind v4 使用 CSS 变量主题令牌翻转：浅色主题基本保持现状，深色主题使用近黑背景与石板灰层级，品牌蓝及红/绿语义色保留并调整明度。清理用户可见的硬编码浅色表面（如白色背景、边框、ring、滚动条），普通文字满足 WCAG AA 对比度。
- 不添加全局主题渐变动画；保留卡片 hover 等局部过渡。
- 影视首页的 PC/Mobile 视图入口继续共享响应式 `MediaHome.vue`，不复制两套业务页面。

### 2. 首页 API 与媒体时间字段

- `GET /media/home` 的 `MediaHomeVo` 新增：
  - `latestMovies: MediaItemVo[]`
  - `latestSeries: MediaItemVo[]`
- 删除原 `recentlyAdded` 字段，不保留兼容字段。
- `MediaItemVo` 新增 `addedTime`，对外时间字符串沿用项目现有 `yyyy-MM-dd HH:mm:ss`、GMT+8 约定。
- `MediaItemType` 增加 `SERIES("series")`。
- 最新电影卡使用 `itemType = movie`；最新剧集卡使用 `itemType = series`，其中 `id` 与 `seriesId` 均为剧集 ID，`fileNodeId` 为空，不伪造代表文件。剧集卡不携带集级进度、时长、季号或集号。
- 最新电影查询电影实体表，最新剧集查询剧集实体表；运行时不为入库时间连接电影文件表、集表或集文件表。标题、海报、评分继续复用既有视图组装逻辑。未匹配或无海报时仍展示，海报回退文件预览缩略图。
- 两个分区分别按各自入库时间倒序，时间相同按实体 ID 倒序稳定排序，各自截取 16 条；两者不合并排序。

### 3. 入库时间冗余字段与 Flyway

- 新增 Flyway `V14__media_recent_added_time.sql`：
  - `t_media_movie.added_time timestamp NULL`：当前电影文件明细中最早的 `create_time`。
  - `t_media_series.latest_added_time timestamp NULL`：当前剧集文件明细中最新的 `create_time`。
  - 历史数据分别按电影文件明细 `MIN(create_time)`、剧集集文件明细 `MAX(create_time)` 回填；无文件明细的实体保持 `NULL`。
  - 两列分别建立 `(user_id, 时间字段 DESC)` 的部分索引，仅索引非空值。
  - 迁移包含字段注释，已完成人工 DDL 确认。
- 电影 `added_time` 维护规则：新增首个文件写入时间；新增后续版本仅在其时间更早时更新；删除当前最早文件时重算剩余文件最早时间；全部文件删除后置空。已有明细重新扫描或内容变化但未重建明细行时不更新。
- 剧集 `latest_added_time` 维护规则：新增集或新增集文件版本时更新为更晚时间；删除当前最新集文件时重算剩余集文件最大时间；全部集文件删除后置空。已有明细重新扫描或内容变化但未重建明细行时不更新。特别篇/第 0 季等只要属于该剧的集文件均参与计算。
- 时间字段与明细新增/删除在同一事务中维护。现有 `min_file_last_modified` 保留，继续表达剧内最早文件修改时间，不替代或删除。

### 4. 首页视觉与相对时间

- 首页新增「最新电影」和「最新剧集」两个独立竖版 2:3 海报横向滚动卡片分区，主标题下显示相对入库时间。
- 五个分区全部为空时显示既有全页空态；任一分区有内容时不显示全页空态。最新电影和最新剧集分别独立隐藏。
- 相对时间按浏览器本地时间计算：小于 1 分钟显示「刚刚」，之后依次为分钟、小时、天（30 天内）、月（12 个月内）、年；未来时间按「刚刚」处理。页面打开期间每 60 秒重新计算一次，不重新请求接口。

## Testing Decisions

- 后端测试缝为 Service 层集成测试：Spring Boot、`application-test.yml`、真实 PostgreSQL，沿用 `MediaHomeServiceTest` 和媒体扫描测试先例；只断言接口返回和数据库外部状态。
- 前端测试缝为 Vitest 的 theme store 测试，沿用 `menu.test.ts` 先例。
- 首页服务测试覆盖：最新电影/最新剧集分离、电影按条目聚合、剧集按剧聚合、各自时间口径、稳定排序、各自 16 条上限、排除其他库、无数据返回空列表、`addedTime` 输出和点击所需类型字段。
- 扫描服务测试覆盖：历史字段回填后的新增/删除维护、电影最早时间、剧集最新时间、全部明细删除置空、已有明细重扫不改变入库时间、事务提交后的最终状态。
- theme store 测试覆盖：三态循环、localStorage 持久化与还原、无效值回退、system 模式跟随 matchMedia 变化。
- CSS/视觉部分不做自动化测试，人工走查浅色/深色、PC/移动端、公开页/主应用非播放页；独立播放页确认保持原样。

## Out of Scope

- hero 大图轮播。
- 独立播放页、视频画布、转码、字幕及播放页外围视觉改版。
- 主题设置页或登录/注册页主题切换按钮；主题唯一手动入口为主应用 Header 图标。
- 影视详情页、媒体库详情页结构改版；这些页面仅获得双主题外观。
- 「其他」类型媒体库进入最新电影或最新剧集。
- 按钮级权限和前端组件级视觉回归测试。
- 跨设备同步主题偏好；主题偏好仅存于当前浏览器 localStorage。

## Further Notes

- 本 PRD 不修订 `media-favorites-and-navigation.md` 的既有行为；该 PRD 未定义影视首页最新内容分区与主题机制。
- 无新增 ADR：双主题 CSS 变量方案、媒体时间字段冗余及首页分区均可逆，未同时满足难以逆转、惊讶性和真实权衡三个 ADR 条件。
- 领域术语已同步至 `CONTEXT.md`：PC/Mobile 共享响应式影视首页、最新电影、最新剧集；原单一「最近添加」术语不再作为首页分区名称。
- 本 PRD 已拆分为工单 01（双主题基础能力）、02（媒体入库时间维护）、03（最新电影与剧集首页 API）、04（影视首页最新内容 UI）。
